grew from `~/Projects/bounties`. The domain has not contracted. The
*surfaces* have.

itself.

## What it refuses

Anything outside bounty and security research. Deep-research *method* →
[chousa](https://github.com/VeigaPunk/chousa-shokunin). Model evaluation →
[kengaku](https://github.com/VeigaPunk/kengaku-shokunin). Secrets →
[kagi](https://github.com/VeigaPunk/kagi-shokunin). Out of province →
report, never absorb.

## How a lane learns

Append-only corpus; every claim separates observation / inference /
unknown; rounds are non-author-verified. See the fleet
[README](https://github.com/VeigaPunk/shokunin#readme).
