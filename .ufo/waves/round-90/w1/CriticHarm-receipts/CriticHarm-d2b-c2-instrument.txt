## D. named limit measured: a bare partner-pattern token is not a shape
fixture: clean HTML with a bare 'ghp_'-prefixed 36-char alphanumeric token (fake, scratch only), no keyword/separator.
landed gate: rc=0, file written, 0 INTAKE-REFUSED; the snapshot contains the value.
scanner shapes at the landing: private-key, op-ref, bearer, authorization, credential, session-cookie,
aws-sts-session-token, aws-access-key-id, gcs-signed-url-signature, azure-sas-signature, cloudfront-signed-url-signature.
A keyworded form ('token: <40 chars>') DOES hit shape=credential; a bare token does not.
This is the README's stated limit ('the gate sees only what the scanner's shapes name'), but it is the
same class S131 documents (GitHub partner patterns), so the L1 should record it as a named limit, not as coverage.
