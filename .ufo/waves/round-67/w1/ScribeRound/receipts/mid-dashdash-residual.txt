## The hole
A stage whose argv carries a `--` separator followed by a **dash-named operand**
(`cut -f1 -- -x missing.txt`, or `cut -f1 -d: big.txt -- -missing.txt`) is counted as ONE input
operand by the candidate's `sigpipe_input_count`, so the candidate keeps the SIGPIPE exemption and
the gate reads `ok`. Real coreutils semantics: after `--`, EVERY later token is a file operand,
including one that starts with `-`. The candidate's counter drops a **leading** `--` only, and then
treats any token starting with `-` (and not `-` itself) as an option — so a post-`--` dash-named
operand is discarded from the count instead of counted.

So the hole needs THREE ordinary things together:
1. a `--` separator (leading or mid-argv), and
2. a post-`--` operand whose name starts with `-` (dash-named files are exactly why `--` exists), and
3. a head that streams and dies of SIGPIPE before reaching it: **`cut` and `grep`** measured.
`head`/`tail` are accidentally safe because their option VALUE (`100000`, `+1`) inflates the
count to 2; `wc`/`sort`/`ls`/`sha256sum` are safe because their own status path is not `-13`;
`cat` is safe because the r66 cat rule refuses any `-`-prefixed token that is not `-` itself.
**`cut` is one of the two frozen repairs (P9).**

The gate's own derive parser accepts the shape: it parses, the stage runs, and the gate scores
it. It is NOT a contrived argv — no shell, no wrapper, no unknown head; only the read-only heads
the repair names.

## What a fix would have to do (NOT done by this seat — this seat edits no production code)
Once a `--` token is seen at ANY position, treat every following token as an operand (after the
positional skip of the head's required non-file args) instead of filtering `-`-prefixed tokens.
That preserves the conservative direction and makes the count >= the true operand count.
Alternatively, refuse every stage whose argv contains a `--` at all — strictly conservative, cannot
mask. The r66 cat rule already refuses such shapes conservatively; the new per-head counter must
not be weaker than the cat rule it sits beside.
