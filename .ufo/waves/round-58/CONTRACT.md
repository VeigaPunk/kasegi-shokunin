# Round 58 proposed contract (pre-implementation)

C1 only: lowest owned depth:verifiability, nominal capability acquisition, legacy score 4 held; coverage 8 and density 9 held subject to no-harm review. No recovered source availability or new frontier row claimed.

CLI `python3 corpus/instruments/kernel-report-assess.py INPUT.json` reads JSON only, never runs supplied steps, opens referenced paths or contacts a target. Output JSON keys `evidence`, `boundary`, `disclosure`, `issues`; exit 0 means assessment completed, NOT accepted report. Malformed shape/read/JSON returns exit 2 with evidence=invalid; unsupported schema returns exit 2. All well-formed incomplete/contradictory assessments return 0.

Input schema `kernel-report-training/v1` (a local teaching format, NOT kernel intake schema):
- `schema` string, `synthetic` true (false refuses as unsupported).
- `version`: {`origin`: string, `id`: string, `recent_check`: boolean}. Only origin `kernel.org`; exact numeric release `N.N[.N][-rcN]` or lowercase 40-hex commit accepted as stable. This is deliberately narrower than all valid upstream identifiers; other stable shapes are needs-evidence, never prove invalid upstream.
- `description`: nonempty string; prose is not semantically interpreted.
- `conditions`: object of string keys/string values, may be empty (explicit none).
- `reproducer`: {`format`: string, `trigger`: string, `confirm`: string, `trace_id`: string}. Supported source/instructions; binary format is unsupported evidence, empty trigger or confirm incomplete.
- `traces`: array of objects {`id`: string, `version`: string, `conditions`: object, `trigger`: string, `observation`: string, `reproduced`: boolean, `operation`: string, `permitted`: boolean, `production`: boolean}. Duplicate IDs invalid. Only selected trace counts; compare version, conditions, trigger and observation to version.id / conditions / reproducer.trigger / reproducer.confirm. All exact comparisons, no natural-language inference.
- `boundary_claim`: {`operation`: string, `permitted`: boolean}. This records expected authority. A matched reproduced trace with same operation, claim.permitted=false, trace.permitted=true and trace.production=true yields `boundary=supported-synthetic`; matching claim.permitted=true or trace.permitted=false or production=false yields `not-supported`; missing/inconsistent evidence yields `unestablished`. No urgency/exploitability/severity or kernel threat-model validity is inferred.
- `ai_assisted`: boolean.
- `public_text`: array of blocks {`kind`: string, `text`: string}; kinds `summary`, `reproducer`, `availability`. Unknown kinds or wrong types invalid. The structured kind is caller annotation, NOT a free-text leak detector. For AI true, any nonempty reproducer block => `disclosure=withhold-reproducer`; otherwise nonempty availability block => `public-status-only`; otherwise `needs-availability-statement`. AI false => `not-assessed` (NOT confidential or approved).

Evidence result `corroborated-synthetic` only when version accepted, recent_check=true, description nonempty, supported reproduction format and nonempty trigger/confirm, selected reproduced trace matches all four evidence bindings. Otherwise `needs-evidence`, with issue codes. Boundary only established when evidence corroborated. AI decision orthogonal to evidence and boundary.

This tool checks internal consistency of synthetic records. It cannot authenticate traces, demonstrate a real reproducer works, establish a real trust-boundary crossing or approve submission. Invented traces must remain labelled synthetic. The accompanying rubric requires human reproduction/threat-model judgment outside this tool. Never execute user-supplied strings.

## Pre-freeze refinement: actual harmless replay is required

Every selected trace additionally has `specimen`: {`actor`: nonempty string, `owner`: nonempty string, `mode`: `buggy` or `fixed`}. The built-in local ACL toy attempts `read-training-record`: buggy permits everyone, fixed permits only actor==owner. The replay derives `permitted` and `observation` (`access-granted` or `access-denied`), not from caller assertions. Trigger must be exactly `read-training-record`; confirm must equal actual replay observation. Trace operation must equal that trigger; trace permitted/observation/reproduced must agree with actual replay (reproduced must be true). Boundary claim.permitted must equal actor==owner (the toy's stated policy), so false self-declarations by an owner cannot create a crossing. No real record, file, kernel or network is read. Missing specimen or unsupported mode produces needs-evidence, never guessed success. Trace fields `version`, `conditions`, `production` remain declared context, not externally authenticated. Boundary result is toy-specific only; production must be true as an asserted scenario constraint but does not certify actual production configuration. Invalid specimen types yield invalid/2. This refinement supersedes the earlier reliance on a reproduced flag alone; nothing was frozen or implemented before this refinement.
