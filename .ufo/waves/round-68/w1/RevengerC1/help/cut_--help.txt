Print specified byte or field columns from each line of stdin or input files

Usage: cut OPTION... [FILE]...

Options:
  -b, --bytes <LIST>                  filter byte columns from the input source
  -c, --characters <LIST>             alias for character mode
  -d, --delimiter <DELIM>             specify the delimiter character that separates fields in the input source (default: Tab)
  -w                                  use any amount of whitespace (Space, Tab) to separate fields (FreeBSD extension)
  -f, --fields <LIST>                 filter field columns from the input source
      --complement                    invert the filter, displaying all but the selected columns
  -s, --only-delimited                in field mode, only print lines which contain the delimiter
  -z, --zero-terminated               filter records separated by NUL instead of newline
      --output-delimiter <NEW_DELIM>  in field mode, replace the delimiter in output lines with this argument
  -n                                  (ignored)
  -h, --help                          Print help
  -V, --version                       Print version

Each invocation must specify exactly one of --bytes, --characters, or --fields. Use - as a file operand to read standard input.
