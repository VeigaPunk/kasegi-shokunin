=== ExecJ9NegCtl — J9 negative controls: the three controls with real outputs ===

The J9 limb is a sourceable bash file that defines check_j9 TREE REF. The
suite core (corpus/instruments/r42-closure.sh) sources it and calls
check_j9 "$EXPORT" "$REF_RESOLVED"; the limb prints ONE payload line
and returns 0 (closed) or 1 (open).

The round-42 suite is authored by a sibling seat and is not committed at
this seat's write time, so the runs below use a r42-SHAPED STAND-IN suite
built in a scratch git fixture: it implements the C1 contract the limb is
written against (export mode only, plain run refused with exit 2, one
'J<n> payload=... closed=0|1' line per check J1-J13, a 'closed=K/13
exit=0|1' tally, an unresolvable ref printing a distinct ref-not-found
red, and R42_DEPTH=1 leaf mode). The stand-in's twelve non-J9 checks are
artifact-driven, so the two control trees score red for a TREE-DEPENDENT
reason and not by accident.

The two control refs are the REAL lane refs, fetched into the fixture repo
from the lane: base 5053a7f46de35784cff4b56756906e9014a38276 and the
round-41 judged head 1f7464612ac4c44e39886b82e812610d3c039b13.
