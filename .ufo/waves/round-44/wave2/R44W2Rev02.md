## Findings

1. **K17 escape is inert for the committed `closed=13/19` occurrence.** In the committed round-43 `claims.json`, line 38 (`before`) says `closed=12/13`; line 41 (`after`) contains `closed=13/19`. K17's documented rule distinguishes measurements (`before`) from targets (`after`); implementation line 326 skips `field == "after"` before line 343 calls `superseded_by()`. Thus the actual 13/19 value never reaches the erratum escape. `.ufo/waves/round-43/claims-erratum-6.md:3` does name `closed=13/19` in a paragraph containing `superseded`, and line 10 itself records that the token is in the after-cell and K17 skips after-cells.

   The requested pattern check **passes**: K17 line 112 defines `ERRATA_RX = ^claims-erratum.*\.md$`; lines 224–226 use it to list errata in the same round directory. `claims-erratum-6.md` matches that regex. A scratch mutant inserting `closed=13/19` into the round-43 C1 *before* cell was superseded by `claims-erratum-6.md`; removing that file made the mutant unbacked. This verifies the escape works for a graded before-token, not for the committed after-token.

2. **The extant K18 marker, not K17, accounts for `13/19` in K18's quote-source records; it self-marks the spot-check prescription.** K18 includes `corpus/lessons/round-43*.md` in its record scope (lines 77, 107–112). Its marker code scans `records` as well as claims errata (lines 152–159), and lines 167–171 add every closed/selftest token on any line containing `Correction (round 43)` to the global superseded set. Spot-check line 101 contains `closed=13/19` and, later on that same line, recommends “Append a `Correction (round 43)` naming the literal…”. Consequently K18's existing rule treats that diagnosis line's own token as superseded; it does not require widening K18 or erratum-6 to do so. This is a self-authorizing marker, not independent evidence that a correction was landed.

   A scratch control confirmed the mechanism: with erratum-6 removed, K18 still had no unbound `closed=13/19`; changing only the line-101 phrase `Correction (round 43)` to `Correction (round 44)` then yielded `K18 payload=quotes=68,bound=52,report-only=1,superseded=10,unbound=5 closed=0`, including unbound `closed=13/19` at spot-check lines 47, 94, and twice at 101. 3. **The SCORECARD occurrence remains outside K17/K18's graded population.** The committed SCORECARD round-43 row is at `SCORECARD.md:1685`; the appended prose correction is at `SCORECARD.md:1691`. K17's population is round `claims.json` files (K17 source lines 154–163), not SCORECARD.
