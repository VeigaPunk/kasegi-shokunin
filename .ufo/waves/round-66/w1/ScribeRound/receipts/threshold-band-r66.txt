=== D. what this means for a counter (the band is real, not noise) ===
The base false green requires the first operand to be larger than the pipe can absorb in
one go: below ~512 KiB cat writes its whole operand, exits 1 with the missing.txt
diagnostic, and the base gate reads 'derive-upstream-exit-1 stale' — NOT a false green.
At and just above 512 KiB the outcome is a genuine race (86/100 at 524288, 90/100 at
528000). From ~540 KiB upward it is 100/100 false green on this host.
Consequences for the counter, stated as design constraints:
  1. A short fixture is VACUOUS for this class: the base is already stale, so the probe
     cannot discriminate candidate from base and a collector could pass an unmodified gate.
  2. A fixture placed IN the 512-528 KiB band is FLAKY: repeated runs of the same
     committed bytes disagree, so a single-run counter is not reproducible.
  3. A fixture comfortably above the band (>= 1 MiB; the r66 probe set uses 4 MiB) is
     deterministic on this host: 200/200 native and 40/40 gate-level.
  4. The threshold is a property of the pipe buffer and cat's chunk size on THIS host.
     It is not a portable constant, so the counter must not encode a size threshold as
     if it were universal; it should assert the NATIVE stage status, which is what the
     r66 probe set already records (native0=-13).
