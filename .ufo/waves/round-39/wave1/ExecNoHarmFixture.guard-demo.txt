     b. no write path the driver declares lies inside a protected root;
     c. `git -C <fixture> rev-parse --show-toplevel` prints <fixture> itself;
     d. (then) it cd's into S -- or DRIVER_CWD, itself under S -- and execs the
        driver there, so relative writes can only land in scratch.
3. A refusing guard exits 90 and the driver never starts.
4. The seat records one positive run AND one refused run, with the refusal's exit
   status and the protected root's digest before/after.  A guard with no recorded
   refusal is prose, not enforcement.
5. `corpus/instruments/ExecNoHarm.sh` is not re-run from the fleet root.
--- end paste-ready clause -----------------------------------------------------

What each measured limb buys, and the limits:

- Limb 2a (guard clause 1, prefix test) is the literal fix cell: cwd outside scratch -> REFUSED, exit 90,
  driver not started, F byte-identical.  This is the M38-7 precondition itself.
- Limb 2b (guard clause 1, protected-root exclusion) exists because a prefix test is
  only as good as the prefix: in this sandbox F is nested under S, so "cwd under S" is satisfied by the
  fleet-root stand-in.  In production F is outside S and either half suffices; the
  exclusion costs one pattern match and removes the nesting hazard.
- Limb 3 (guard clause 2, declared writes) is a declaration check, so it cannot see an
  undeclared absolute write.  It is defence in depth; clause 1 is the enforcement.  A driver
  that genuinely needs an absolute target must be given one under S.
- Limb 4 (guard clause 3, toplevel) is the second half of the fix cell with teeth: the unguarded
  control (limb 4b) shows a nested fixture turning the misroot into a commit
  ("7 files changed, 7 insertions(+), 100 deletions(-)" -- the truncation is now in
  the enclosing repo's history).  A toplevel assertion before `git add`/`commit`
  refuses that path.
- Cost, measured: one wrapper invocation plus five environment variables; the whole
  demo (one fake fleet root, five fixture-repo rebuilds, three git histories) takes
  roughly a second on this host (wall time recorded at the end of this transcript).
- Scope of the demonstration: F is a stand-in built inside seat scratch, so the
  damage in limb 1 and limb 4b lands on copies, never on the fleet root or the lane.
  No lane or fleet file was written by this seat; only $S was.

#!/usr/bin/env bash
# guard-run.sh -- the round-39 mandated guard for fixture drivers (closes M38-7).
#
# Clauses, evaluated in order, before the driver's first instruction runs:
#
#   1 CWD        the caller's cwd must already be under $SCRATCH_ROOT and must not
#                be inside a protected root ($FLEET_ROOT).  The M38-7 precondition
#                -- cwd = the fleet root -- violates the second half; a seat shell
#                that has not cd'd into scratch violates the first.
#   2 WRITES     every absolute path the driver declares it will write must lie
#                outside $FLEET_ROOT.  This is a declaration check (defence in
#                depth): it cannot see a write the driver does not declare.
#   3 TOPLEVEL   the fixture used for git mutations must be its own worktree root:
#                `git -C "$FIXTURE_DIR" rev-parse --show-toplevel` == "$FIXTURE_DIR".
#                Nested fixtures are refused, because `git add -A` from a
#                subdirectory stages the whole enclosing worktree.
#   4 CD+EXEC    cd into $DRIVER_CWD (default $SCRATCH_ROOT; must be under scratch)
#                and exec the driver, so relative writes can only land in scratch.
#
#   usage: SCRATCH_ROOT=<S> FIXTURE_DIR=<D> [FLEET_ROOT=<F>] [DRIVER_WRITES="<abs> ..."] \
#          [DRIVER_CWD=<dir under S>] guard-run.sh <driver> [driver args...]
#
# Exit: driver's own status when it runs; 90 when a clause refuses (driver never starts).

set -u -o pipefail

S=${SCRATCH_ROOT:?SCRATCH_ROOT unset}
D=${FIXTURE_DIR:?FIXTURE_DIR unset}
FLEET=${FLEET_ROOT:-}
WRITES=${DRIVER_WRITES:-}
RUN_CWD=${DRIVER_CWD:-$S}

refuse() {
  printf 'guard: REFUSED [%s]: %s\n' "$1" "$2" >&2
  printf 'guard: driver not started\n' >&2
  exit 90
}

# clause 1 -- caller cwd under scratch, and outside every protected root
caller=$(pwd -P)
case $caller in
  "$S" | "$S"/*) ;;
  *) refuse CWD "caller cwd '$caller' is not under scratch '$S'" ;;
esac
if [ -n "$FLEET" ]; then
  case $caller in
    "$FLEET" | "$FLEET"/*)
      refuse CWD "caller cwd '$caller' is inside protected root '$FLEET'" ;;
  esac
fi

# clause 2 -- no declared write inside the fleet root
if [ -n "$FLEET" ]; then
  for p in $WRITES; do
    case $p in
      "$FLEET" | "$FLEET"/*)
        rel=${p#"$FLEET"/}
        if git -C "$FLEET" cat-file -e "HEAD:$rel" 2>/dev/null; then
          refuse TRACKED-WRITE "declared write '$p' is inside fleet root '$FLEET' and is tracked at HEAD"
        fi
        refuse FLEET-WRITE "declared write '$p' is inside fleet root '$FLEET'"
        ;;
    esac
  done
fi

# clause 3 -- fixture must be its own worktree root
top=$(git -C "$D" rev-parse --show-toplevel 2>/dev/null) ||
  refuse NOT-A-REPO "fixture '$D' is not inside a git worktree"
[ "$top" = "$D" ] ||
  refuse TOPLEVEL "fixture toplevel '$top' != fixture dir '$D'"

# clause 4 -- move into scratch, then hand over
case $RUN_CWD in
  "$S" | "$S"/*) ;;
  *) refuse CD "DRIVER_CWD '$RUN_CWD' is not under scratch '$S'" ;;
esac
cd "$RUN_CWD" || refuse CD "cannot enter '$RUN_CWD'"
printf 'guard: PASS [cwd=%s toplevel=%s fleet=%s]\n' "$(pwd -P)" "$top" "${FLEET:-none}"
exec "$@"
[exit 0]
