== Findings ==

F-A (coverage defect, M2): the Frontier row's `sources` cell is parsed by no committed instrument.
    frontier-recheck-count.py's FRONTIER_ROW regex stops at cell 4; the entry<->source binding is
    taken solely from the entry's own `source:`/evidence lines. Swapping the row's source to
    another entry's source (S055, F21's source) leaves every frozen C2 counter at its frozen value
    (frontier 22, registry 59, harness 25/25, binding 46/46, audit expected=51 — none read this
    cell). The claim's E5.9 sentence is the only pin on this cell and it is prose, not a counting
    command. A one-line guard (harness asserts the row's cell-5 ids are a subset of the entry's
    declared set) would close it.

F-B (row-shape / row-drop blind spot, M1/M3/M4a/M4b): the harness never validates row width
    against the header and treats a regex-non-matching row as absent rather than as an error. Four
    of six row mutations survive with exit 0; two of them (M1, M3) also keep the frozen frontier
    grep count at 22. A dropped or malformed admitted row shrinks the measured surface silently;
    only the entries=25 count notices, and only when the drift crosses the frozen number.

F-C (rule-D escape, C-ESC vs M5b/C-DIGEST): evaluate() executes the recheck line with cwd=root,
    but the line's own leading `cd /home/vgpnk/Projects/shokunin/kasegi-shokunin &&` overrides it,
    so the exit-code limb is bound to a hardcoded absolute path, not to --root. With the cd intact
    the harness prints PASS for a mirror whose capture is corrupted (C-ESC); with the cd dropped
    the same corruption is red (M5b). At the live lane the cd target equals root, so the frozen
    counting command is unaffected today — but any run at a different --root (export, mirror,
    relocated checkout) certifies the hardcoded tree, not the one under test. The root-bound
    (cd-less) form of the line also passes (M5), so the prefix is load-bearing for nothing the
    harness checks.

F-D (what holds): the fail-closed limbs work as documented where they bind — missing-entry (M4c),
    manifest-unreadable (M6), and the executed recheck's own digest check (M5b, C-DIGEST) all fire
    red with named-row problems, and the pristine baseline and final restored run both print the
    frozen entries=25 pass=25 exit=0.

Claim impact: C2's harness limb is real but narrower than its receipt line. The row-level binding
(sources cell, row shape, row presence) is enforced only by the frozen entries=25 count (M1/M3/M4a
drift it) and the E5.9 prose predicate (M2); M4b flips nothing at all; and the executed recheck is
bound to a hardcoded path rather than to the harness root (C-ESC). No mutation made a frozen
counter report a false green count — the survivors survive by leaving the counters untouched.
