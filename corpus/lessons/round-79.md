## Learning

- **Expansion.** F55 is the first admission of a *pre-vulnerability* step: the page turns vendored C/C++ file bytes into a candidate upstream library and version, which is the input a query needs. The coverage map held this subject only from the query side (F51 single query, F54 batch); the frontier moves 54 -> 55 with one entry, not a second reading of an endpoint already mapped.
- **Quality.** The instrument work is where quality moves: the successor turns an unobservable assertion into two observable structures, and the selftest grows from six (`cases=6` at base) to fifteen, so the pin rows in `SKILL.md` and `corpus/instruments/README.md` move from `selftest cases=6` to `cases=15` in the same commit as the counter (QUALITY R113), with P2 binding the landed bytes to `eda49d32…`.
- **Discernment.** The three rejects are one distinction applied three times: a line that restates held ground (:37, :64) or points into it (:39) is not a new clause however true it is. The appended correction adds the other half: a reject must name the ground it rests on, and the round-78 spot-check showed the outcome can be right while the cited reason is wrong — outcome and reason are checked separately.
- **Verifiability.** The K-X2 class is now measured as *output equivalence*, not by reading the transform: two runs whose normalized outputs differ by zero lines cannot distinguish mutant from candidate, so the row proves nothing about the assertion it claims to attack. That is the cheap move later rounds should make first (M79-1, proposed R128), and it is why the round-79 fix puts the check in structure rather than in one more hand-written assertion.
- **Freeze discipline.** M79-2 is the complementary lesson: the counter that defines a kill is itself a frozen artifact with a contract, and its classifier is part of that contract. A target count that the frozen counter cannot print is a freeze defect found only by scoring the battery, and it belongs to the claim, not to the candidate — the candidate's assertion for that row did fail. Both lessons say the same thing in different places: a verifiability claim is only as strong as the weakest metadata it rests on, so the counter's classifier is selftested on the hard case (an assertion detail that mentions an exception) before the freeze, the way the manifest is rechecked once before its success predicate binds (R126).
